CLIENT HUB WEBSITE — EXPANDED VERSION

Preview:
Open index.html in a web browser.

IMPORTANT — CONNECT YOUR DISCORD INVITE:
1. Open index.html in Notepad or another text editor.
2. Find every occurrence of https://discord.com/
3. Replace it with your actual server invite, e.g. https://discord.gg/YOURCODE
4. Save the file.

To get your invite, open your Discord server and choose Invite People. Check the invite's expiry and usage settings before sharing it.

PUBLISH FOR FREE USING GITHUB PAGES:
1. Sign in at https://github.com/
2. Create a public repository named client-hub-website.
3. Upload index.html and commit the changes.
4. Open repository Settings > Pages.
5. Select Deploy from a branch, choose main and /(root), then Save.
6. Wait for GitHub Pages to publish. The URL appears in Settings > Pages.

Official guide: https://docs.github.com/en/pages/quickstart

This is a static website. It does not connect to Discord, display live member counts, or create tickets itself. The ticket instructions point visitors to your Discord server. A custom domain is optional.
